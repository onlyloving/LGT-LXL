# LGT-LXL 六级单词（.NET MAUI 安卓应用）

包名 `com.lgtlxl.vocab` ｜ 版本 1.0 ｜ 应用名 **LGT-LXL** ｜ 解锁密码 **lgt520lxl**

## 一、怎么安装

1. 把 `LGT-LXL-六级单词对战-v1.0.apk` 传到手机上（微信、QQ、数据线都可以）。
2. 在手机上点开安装，第一次会提示「未知来源应用」，允许一下即可。
3. 以后重新打包的版本可以直接覆盖安装，因为用的是同一个签名文件。
4. 打开 App 后输入密码 `lgt520lxl`；勾上「在这台手机上记住密码」，下次就不用再输了。

## 二、功能

1. **内置六级词库**：百词斩 CET6 三本词书合并去重，共 **3991 个单词**，每个词都有音标、中文释义和例句，全部打包在 App 里。
2. **两个用户各自记进度**：LGT 和 LXL 的已学词数、掌握词数、连续打卡天数、对战成绩完全分开，随时切换身份。
3. **单词对战**：从两人已学单词里抽 **50 词或 100 词**，每题 1 分，分高者胜，结果写进历史战绩。
   - 本机轮流：一部手机，两个人先后答同一套题。
   - 联机对战：两台手机连同一个 Wi-Fi / 热点直连，不用流量、不需要服务器。
4. **完全离线**：词库在 App 内，进度存手机本地，飞行模式也能背单词、记进度、看战绩。
5. **背单词节奏**：先复习到期的词，再补新词；答对升级、答错回到第 1 级，按 1 / 2 / 4 / 7 / 15 / 30 天的间隔安排复习。

## 三、联机对战怎么用

1. 两台手机连到同一个 Wi-Fi；或者一台开手机热点、另一台连这个热点。
2. A 手机：单词对战 → 选词数（50/100）→ 联机对战 → 创建房间，屏幕会显示一个 IP。
3. B 手机：单词对战 → 选词数 → 联机对战 → 输入那个 IP → 点「加入」。
4. 两边同时答题，答完自动对比分数并记录战绩。

连不上通常是这两种原因：两台手机不在同一个网络；或者手机热点开启了「设备隔离」，换一个热点或 Wi-Fi 再试。

## 四、改代码 / 重新打包（Visual Studio）

1. 解压 `LGT-LXL-源代码-v1.0.zip`，用 Visual Studio 2022 或 2026 打开 `LgtLxlVocab.csproj`（需要安装 .NET MAUI 工作负载）。
2. 改成 Release + `net10.0-android` 后「生成 → 发布」，就会得到新的 APK。
3. 工程里带了签名文件 `LgtLxl.keystore`（别名 `lgtlxl`，密码 `lgt520lxl`），换电脑打包也能覆盖安装。
4. 想换词表：直接替换 `Resources/Raw/cet6_words.json`（格式是 `word/phonetic/translation/example/exampleCn` 的数组）。
5. 想改密码：`AppState.cs` 里的 `Password` 常量。
6. 界面代码是纯 C# 写的（没有 XAML 页面）：`Pages1.cs` 锁屏/选用户/首页，`Pages2.cs` 背单词/进度/词表，`Pages3.cs` 对战设置/联机房间，`Pages4.cs` 答题/结果/战绩，`LanBattle.cs` 是联机通信。

## 六、技术说明

- 框架：.NET MAUI（.NET 10，`net10.0-android`，Android 7.0+，目标 SDK 36）
- 数据：全部在 App 私有目录的 JSON 文件里（`lgtlxl/profiles.json`、`lgtlxl/words.json`），不联网、不上传。
- 联机：`System.Net.Sockets` 的 TCP 直连，端口 47615。
- 打包：Release、关闭裁剪与 AOT（体积换稳定，避免反射/JSON 在个别机型上被裁掉），APK 用 `LgtLxl.keystore` 签名。
