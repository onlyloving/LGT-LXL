## 一、安装

把 `LGT-LXL-v1.5.apk` 传到手机上安装，会**直接覆盖旧版本，进度不丢**。
第一次安装要允许「未知来源应用」；打开后输入密码 `lgt520lxl`（可勾选记住）。

## 二、v1.5 修的两个大问题

### 1. 「单词对战」点进去变成背单词界面 —— 已修

- 原因：之前如果两人已学单词不足 5 个，程序会**默默跳去背单词页**（重装 App 后进度清空，必然触发）。
- 现在改成明确提示，并给你两条路：
  - **📖 先去背单词**：学几个词再来对战；
  - **🎲 用词库随机词开一局**：即使还没背过单词，也能立刻开一局（本机轮流 / 联机都行，专门用来试联机）。
- 只要两人已学单词够，本机轮流和联机对战都会直接进入答题界面。

### 2. 同一个网络也连不上（联机对战 / 同步进度）—— 已修

这次改动：

- **房主会显示自己所有可用地址**，并标注是 Wi-Fi 还是热点，例如：
  `192.168.1.5（Wi-Fi） / 192.168.43.1（热点）`，加入方照着输就对得上；
- **自动搜索更可靠**：除了受限广播，还会向每个网卡的子网广播地址发探测包，并显示房主的真实来源地址；
- **端口被占用会自动换**（47615 → 47617 …），屏幕上会写明**实际端口**；手动输入可以写 `192.168.1.5:47617`；
- **连接超时（12 秒）会给出具体原因**，不再是干等；
- 联机对战时，抽题范围改成「房主手机上两人的已学单词 ∪ 加入方报告的已学单词」。

**连不上时的排查顺序（照着做基本都能通）**

1. 两台手机连**同一个** Wi-Fi（注意别一个连 2.4G、一个连 5G 的不同 SSID 而实际隔离）；
2. 最好用**一台手机开热点、另一台连热点**——这种直连最稳，不依赖路由器；
3. 房主先点「创建房间 / 发起同步」，屏幕上出现地址后，另一方再点「自动搜索」或输地址；
4. 校园网、公共 Wi-Fi、部分路由器会开「设备隔离/AP 隔离」，这种情况下**任何两台设备互相都连不上**，必须改用热点；
5. 加入方输地址时，要输**房主屏幕上列出的那个**（如果房主有多个地址，可以每个都试一下）。

## 三、功能总览

### 背单词（两关制）

首页 → **📖 背单词（学新词）**

- 第 1 关：**英语 → 中文**；第 2 关：**中文 → 英语**（第 1 关过了隔 2 题出现）
- **两关都答对**才算真正背过，才计入「已学」并进入复习计划
- 任意一关答错，这个词**重新排回队列，直到答对为止**（答错时显示音标、释义、例句）

### 复习

首页 → **🔁 复习**（显示「今日有 N 个词到期」）

- 优先复习**到期**的词（1/2/4/7/15/30 天间隔）；没到期就随机抽已学单词
- 掌握等级 ≤2：过两关；等级 ≥3：只考「中文 → 英语」
- 答对 → 等级 +1、下次复习往后推；答错 → 回到第 1 级并稍后重考

### 单词对战

首页 → **⚔️ 单词对战** → 选 50 / 100 词 → 选方式：

- **本机轮流**：一台手机，两个人先后答同一套题，自动比分；
- **联机对战**：房主「创建房间」，另一方「自动搜索」或输地址；两边同时答题，答完自动对比并记录战绩。

### 同步进度

首页 → **🔄 同步进度（两台手机）**

- 一台「📡 我来发起同步」，另一台「🔍 搜索」或输地址；
- 合并内容：单词进度（同一个词以复习时间更近的为准）、每日统计、对战记录（去重）；
- 同步后两台手机的「学习进度」页都能看到**两个人**的数据。

### 其他

- 内置百词斩 CET6 词库 **3991 词**（音标 + 中文释义 + 例句），离线可用；
- LGT / LXL 各自独立记录已学、掌握、连续天数、对战战绩；
- 学习进度页可看两人对比、已学单词，也可浏览全部词库。
